## 🛠️ Quick Commands

### Code Analyzer
```bash
# Install
cd code-analyzer
pip install -r requirements.txt

# Analyze a Python file
python -m code_analyzer analyze myfile.py

# Analyze a project
python -m code_analyzer analyze /path/to/project --recursive

# Generate full report
python -m code_analyzer report /path/to/project --output ./report
```

### Login Website

**Backend:**
```bash
cd login-website/backend
npm install
npm start
# Server: http://localhost:5000
```

**Frontend:**
```bash
cd login-website/frontend
npm install
npm start
# App: http://localhost:3000
```
