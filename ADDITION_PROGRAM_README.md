# Addition Program

A simple Python program that performs addition operations on two numbers.

## Features

- Accepts two numbers as input from the user
- Performs addition operation
- Displays the result in a clear format
- Includes error handling for invalid inputs

## How to Run

```bash
python addition_program.py
```

## Usage Example

```
=== Addition Program ===

Enter first number: 10
Enter second number: 5

10.0 + 5.0 = 15.0
```

## How It Works

1. The program prompts the user to enter the first number
2. The program prompts the user to enter the second number
3. The `add()` function performs the addition operation
4. The result is displayed to the user
5. If invalid input is provided, an error message is shown

## Functions

### `add(a, b)`
- Adds two numbers
- Returns the sum

### `main()`
- Entry point of the program
- Handles user input and output
- Includes error handling
